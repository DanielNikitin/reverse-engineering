Меняют способы реализации одних и тех же задач:

Как загрузили драйвер
(обычная установка / уязвимый драйвер / мануальный маппер / другой эксплойт)
Как спрятали следы
(стирание PE-заголовков / правка прав секций / удаление из списка модулей / другие трюки)
Как общаемся с usermode
(реестр / IOCTL на Null / shared memory / другой канал)
Как читаем память
(через CR3 / физическая память / другой метод)
Какие ещё следы оставляем
(потоки, колбэки, пулы, тайминги и т.д.)
Как это выглядит на практике
Собрал рабочий вариант → забанило.
Поменял только метод скрытия (или только канал связи) → проверил снова.
Если баны пропали — значит, палился предыдущий метод скрытия.
Если нет — меняешь следующую часть и повторяешь.
Так по шагам находят, какой именно приём в данный момент детектится, и заменяют его на другой. Именно это имелось в виду под «отключать/менять функции последовательно».
